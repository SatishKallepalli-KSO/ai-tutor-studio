Integration

API reference

FastAPI surface for partners, mobile clients, or white-label frontends. Interactive docs: /docs on a running API.

Auth

MethodPathNotes
POST /v1/auth/register Body: email, password (≥8), name → JWT + user
POST /v1/auth/login Body: email, password → JWT + user
GET /v1/auth/me Bearer token → plan, quota, free tracks

Tutor

MethodPathNotes
GET /v1/tutor/tracks Catalog of tracks
GET /v1/tutor/tracks/{id}/questions Practice bank with topic_id
GET /v1/tutor/tracks/{id}/access can_learn / can_practice / requires_pro
POST /v1/tutor/feedback Auth required. Body includes input_mode: text|voice

Paywall errors

HTTP 402 with structured detail:

{
  "detail": {
    "code": "track_locked|quota_exceeded",
    "message": "Human-readable upgrade prompt"
  }
}

Billing

MethodPathNotes
GET /v1/billing/plans Public plan cards + stripe_enabled flag
POST /v1/billing/checkout Auth · { "interval": "month"|"year" } → Checkout URL
POST /v1/billing/portal Auth · Stripe Customer Portal URL
POST /v1/billing/webhook Stripe events (no JWT)
POST /v1/billing/demo-upgrade Auth · local/pilot Pro when Stripe unset

Health
