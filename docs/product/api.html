API reference

FastAPI v0.6 surface for the web app, partners, and white-label clients. Interactive docs: /docs on a running API.

Auth

Method Path Notes
POST /v1/auth/register email, password, name, persona learner|recruiter
POST /v1/auth/login → JWT + user
GET /v1/auth/me plan, quota, persona, is_admin
PATCH /v1/auth/me/persona { "persona": "learner"|"recruiter" }

Tutor

Method Path Notes

GET /v1/tutor/tracks/{id}/questions Bank with topic_id
GET /v1/tutor/tracks/{id}/access can_learn / can_practice / requires_pro
POST /v1/tutor/feedback Auth · input_mode: text|voice
