1. What you deploy

Piece Role Production
API (apps/api) Auth, plans, Stripe, AI feedback, custom questions + quota, scorecards, jobs, profiles, admin Required
Web (apps/web) Learn/Hire launchpads, Practice hub, Your question, Agentic path, packs/mocks, pricing, admin Required (bundled in Docker)

Product: Learn, practice, get AI feedback. Flagship: Practice your own question (2 custom AI feedbacks/topic free). Live shape: Render Free Docker + Neon Free + OpenAI. See PRODUCTION.md.

2. Pre-flight

  • Public HTTPS URL decided (e.g. https://app.yourdomain.com)
  • OpenAI account with billing + API key
  • Stripe account (test mode first, then live)
  • Admin emails for ADMIN_EMAILS
  • Strong random JWT_SECRET (32+ chars)
  • Postgres ready (avoid SQLite for real traffic)
  • ALLOW_DEMO_UPGRADE=false in production
python3 -c "import secrets; print(secrets.token_urlsafe(48))"

3. Environment variables

Variable Required Notes
JWT_SECRET Yes Long random string
APP_URL Yes Public UI origin for Stripe redirects
DATABASE_URL Recommended postgresql://user:pass@host:5432/db
OPENAI_API_KEY Recommended Enables model coaching
OPENAI_TUTOR_MODEL No Default gpt-4o-mini
STRIPE_* For pay Secret, prices, webhook
ALLOW_DEMO_UPGRADE Must be false live Local-only Pro unlock when Stripe off
ADMIN_EMAILS Recommended Comma-separated → /admin access

4. Integrate AI (OpenAI)

Setup Create API key

platform.openai.com → API keys. Add billing. Set OPENAI_API_KEY. Keep model on gpt-4o-mini to start.

Behavior With / without key

With key: richer coaching on bank + custom prompts. Without key: rubric fallback still works for demos. UI shows Content / Clarity / Delivery.

Smoke test

curl -s https://YOUR_HOST/healthz

# After register/login, POST feedback with Bearer JWT
# (bank question_id or custom_prompt). Confirm provider=openai.

Free: 5 bank feedbacks/day + 2 custom AI feedbacks/topic — watch OpenAI usage once Pro unlimited is live.

5. Integrate payments (Stripe)

  1. Products → add Practice Out Loud Pro with monthly ($19) and yearly ($149) prices. Copy Price IDs into env.
  2. Webhooks → https://YOUR_HOST/v1/billing/webhook · events: checkout.session.completed, customer.subscription.updated, customer.subscription.deleted.
  3. Enable Customer Portal. Set APP_URL for redirects.

Payment smoke test (test mode)

  1. Register → /pricing → Upgrade → Checkout
  2. Card 4242 4242 4242 4242
  3. Confirm webhook delivered in Stripe
  4. App shows Pro; tracks + packs unlock; unlimited bank + custom feedback
  5. Portal cancel → Free after webhook
