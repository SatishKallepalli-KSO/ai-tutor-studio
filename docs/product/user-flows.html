Experience design

User flows

Core journeys buyers care about: acquisition through free docs, practice conversion, voice interview simulation, and paid upgrade.

1) Primary learning loop

flowchart TD A[Land on tracks] --> B[Pick a track] B --> C[Learn: topic documentation] C --> D{Ready to practice?} D -->|Yes| E[Practice question] D -->|Keep reading| C E --> F[Type or Speak answer] F --> G[Get AI / rubric feedback] G --> H[Next drill / next topic] H --> C

Sellable insight: Docs are free for every track so users feel progress before hitting a paywall — same pattern as freemium coding platforms.

2) Registration & first value

flowchart LR A[Start free] --> B[Register email + password] B --> C[JWT stored locally] C --> D[Pricing page optional] C --> E[Practice free tracks] E --> F[Feedback within daily quota]
  1. Create account from /register.
  2. Immediately practice HTML/CSS/JS/Python with voice or text.
  3. See coaching (score, gaps, delivery tips).
  4. Hit Staff/EM or quota → Upgrade CTA.

3) Voice interview practice

sequenceDiagram actor Candidate participant UI as Practice UI participant Mic as Browser Speech API participant Coach as Feedback engine Candidate->>UI: Hear question TTS Candidate->>UI: Speak answer UI->>Mic: continuous recognition Mic-->>UI: transcript into answer box Candidate->>UI: Get voice + content feedback UI->>Coach: input_mode=voice Coach-->>UI: content coaching + delivery_tips UI-->>Candidate: Spoken grammar / fillers / pacing
  • Interviews are oral — product mirrors that with mic-first practice.
  • Transcript is editable before submit (fix speech-to-text mistakes).
  • Works in Chrome / Edge / Safari; typed fallback always available.

4) Paywall & upgrade

flowchart TD A[Attempt practice / feedback] --> B{Signed in?} B -->|No| C[Prompt create account] B -->|Yes| D{Pro or free track?} D -->|Pro-only track| E[Show Pro paywall] D -->|Free track| F{Daily quota left?} F -->|No| E F -->|Yes| G[Return coaching] E --> H[Pricing: monthly / yearly] H --> I{Stripe configured?} I -->|Yes| J[Checkout session] I -->|No| K[Demo upgrade for pilots] J --> L[Webhook → plan=pro] K --> L L --> G

5) Personas & happy paths

IC candidate (Staff)

Browse Staff docs free → upgrade for mock ownership / design / AI-safety questions → voice STAR answers.

Engineering Manager

Study people + vendor transition docs → Pro practice opener / conflict stories out loud.

Java → AI upskiller

Path + RAG + Agents docs → practice explaining systems in spoken form for internal mobility interviews.

Language learner

Free HTML/CSS/JS/Python loop → convert to Pro for TS/React/Java/Node interview depth.
