User flows

Learner and recruiter journeys: study → practice → profile → network → jobs, plus paywall conversion.

1) Learner learning loop

flowchart TD A[Land Learn] --> B[Pick track or video path] B --> C[Topic docs] C --> D{Ready?} D -->|Practice| E[Speak or type] D -->|Keep reading| C E --> F[AI / rubric feedback] F --> G[Next topic / drill] G --> C

2) Recruiter hiring loop

flowchart TD A[Switch to Recruiter] --> B[Post job] B --> C[Talent browse / open-to-work] C --> D[Connect request] D --> E{Accepted?} E -->|Yes| F[Message] E -->|Pending| D F --> G[Invite to practice / interview]

3) Registration & persona

flowchart LR A[Register] --> B[Pick Learner or Recruiter] B --> C[JWT + persona] C --> D[Learner home /] C --> E[Recruiter home /jobs] D --> F[Profile Network Chat] E --> F
  1. Sign up with persona picker (or switch anytime in header).
  2. Learners land on tracks; recruiters prefer Jobs.
  3. Same account can switch roles without a second signup.

4) Network & chat

sequenceDiagram actor A as User A actor B as User B participant Net as /network participant API participant Chat as /messages A->>Net: Discover → Connect + note Net->>API: POST /v1/connections B->>Net: Incoming → Accept Net->>API: PATCH accepted A->>Chat: Open thread Chat->>API: POST /v1/messages API-->>Chat: Deliver if connected

5) Voice practice

sequenceDiagram actor Candidate participant UI as Practice UI participant Mic as Web Speech API participant Coach as Feedback Candidate->>UI: Hear question TTS Candidate->>UI: Speak answer UI->>Mic: recognition Mic-->>UI: transcript editable UI->>Coach: input_mode=voice Coach-->>UI: content + delivery_tips

6) Paywall

flowchart TD A[Practice / feedback] --> B{Signed in?} B -->|No| C[Register] B -->|Yes| D{Pro or free track?} D -->|Locked| E[Pricing] D -->|Free track| F{Quota?} F -->|Empty| E F -->|OK| G[Coaching] E --> H{Stripe?} H -->|Yes| I[Checkout] H -->|No| J[Demo upgrade] I --> G J --> G
